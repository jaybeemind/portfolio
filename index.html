01

NGCP · Energy operations

Grid and market data in one view

A dashboard for operations teams working to the electricity market’s five-minute settlement intervals.

My contribution
Led Project Sentinel and the 5-Minute Real-Time Dashboard, bringing SCADA telemetry and market data into a shared view.
Key decision
Align data to the settlement interval and show how recent each input is.
Result
Operations and market interface teams could use the same dashboard for their interval checks.
  • Laravel
  • Vue.js
  • Node.js
  • Oracle DB
  • SCADA
02

NGCP · Systems integration

One sign-in across internal applications

Separate logins and user records made access difficult to manage across an existing set of business applications.

My contribution
Led Single Sign-On and Market Data Interchange projects for internal systems.
Key decision
Let each application adopt central sign-on incrementally, around its team’s release schedule.
Result
A shared identity service for existing applications and new internal tools.
  • Laravel
  • Node.js
  • Vue.js
  • Oracle DB
  • SSO
03

Legacy systems · Data migration

Oracle to PostgreSQL, with checks built in

Business data needed to move to a new database while day-to-day operations continued.

My contribution
Built a pipeline to transform legacy Oracle structures into a PostgreSQL model.
Key decision
Reconcile record counts, keys, and business totals while running the systems side by side.
Result
A repeatable migration process with differences available for review before switching systems.
  • Python
  • Oracle
  • PostgreSQL
  • Node.js
  • Data reconciliation
04

Comtrac, via GoTeam · Investigation software

Maintaining a live casework platform

Investigation records need careful validation, while investigators need different ways to search and read them.

My contribution
Delivered Vue 3 and .NET features, maintained the platform, and contributed to its CQRS architecture.
Key decision
Separate changes to records from the models used to query them.
Result
New views could be developed with less dependence on the model used to write case records.
  • Vue.js 3
  • C# / .NET
  • CQRS
  • Azure
  • CI/CD

05 / Independent project

ROOC Guild Management

A working application for guild rosters, loot auctions, and rewards. I designed and built the system from the workflow through to deployment.

The design decision
Give each auction a fixed lifecycle and preserve its history. Finalized assignments stop being editable, and role-based permissions control who can make changes.
What it supports
Member rosters, reward catalogs, auction results, and an append-only audit log.
  • Cloudflare Workers
  • Role-based access
  • Audit history
